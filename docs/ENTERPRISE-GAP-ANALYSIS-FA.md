## تصمیم‌های اولیه

- هیچ جدول یا migration اجباری به پکیج اضافه نمی‌شود.
- رجیستری فقط کلاس/توصیف ثابت نگه می‌دارد؛ تعریف مدل در اجرای سرور تازه ساخته می‌شود.
- sources تعریف‌نشده، رفتار قدیمی را حفظ می‌کند؛ sources خالی به معنی داده صفر است.
- Closureهای تعریف مدل فقط سمت سرور هستند و در وضعیت عمومی Livewire قرار نمی‌گیرند.
- تغییرات قبلی کاربر حفظ می‌شوند. توسعه سازمانی تا اجرای آزمون‌های واقعی آماده انتشار محسوب نمی‌شود.
