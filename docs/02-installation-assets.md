# نصب و دارایی

میزبان دارای Tailwind 4 و DaisyUI 5 با تنظیمات پیش‌فرض باید `resources/css/kanban.css` منبع بسته را در CSS سراسری import کند؛ این فایل اسکن نماها را با `@source` فعال می‌کند و رنگ‌ها را از متغیرهای میزبان می‌گیرد. [مسیر import، توکن‌ها و قرارداد انتخابگرها](11-views-customization.md). فایل آماده `resources/dist/kanban.css` فقط برای نصب مستقل است و Tailwind/DaisyUI و بازنشانی عمومی CSS را شامل می‌شود؛ آن را هم‌زمان با CSS میزبان بارگذاری نکنید. JavaScript آماده با تگ `kanban-assets` به `public/vendor/kanban` منتشر می‌شود. اسکریپت پکیج `Alpine.start` یا `Livewire.start` را صدا نمی‌زند. CSP باید `self` را برای همان مسیر vendor اجازه دهد.
