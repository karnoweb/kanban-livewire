# KD001 — بخش‌های جزئیات اختیاری و امن

آزمون اجراشدنی: `tests/Feature/CardDetailsProviderTest.php`.

ورودی: یک کارت در برد محدودشده و Provider اختیاری با بخش‌های تعریف‌شدهٔ سرور. بازکردن Drawer نباید رکوردهای بخش را بارگذاری کند. بازکردن یک بخش تنها همان صفحه را می‌خواند؛ cursor بعدی صفحه‌ای محدود می‌دهد.

انتظار: نه نوع بخش از یک قرارداد استفاده می‌کنند. مجوز نظرها اجازهٔ فایل‌ها نیست؛ بخش ممنوع با فراخوانی مستقیم هم خوانده نمی‌شود. لغو مجوز دادهٔ قبلی را پاک می‌کند. حذف کارت Drawer را می‌بندد. متن مخرب escape و URL اسکریپتی رد می‌شود. عمل تعریف‌نشده اجرا نمی‌شود و نتیجهٔ unknown موفق نیست؛ تلاش مجدد همان شناسهٔ عملیات را دارد.

نتیجهٔ آخرین اجرای مجموعه در `docs/K1-K5-RESULTS.json` ثبت شده است؛ این سند به‌تنهایی ادعای اجرای آزمون نیست.
